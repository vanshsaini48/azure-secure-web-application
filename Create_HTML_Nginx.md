# STEP 5: Create an HTML Page in Nginx and Restart Nginx

## Overview

This step covers creating a custom HTML page and deploying it to the Nginx web server running on the Azure virtual machine.

## Configuration

The following steps are performed:

1. Connect to the virtual machine through Azure Bastion
2. Create a custom HTML page
3. Place the HTML file in the Nginx web root directory
4. Restart the Nginx service
5. Verify that the web page is being served correctly
