# STEP 2: Create a Virtual Machine inside the VNet

## Overview

This step covers creating an Ubuntu virtual machine inside the Azure Virtual Network.

The VM is deployed within the configured subnet and is used to host the web application.

## Configuration

The following settings are configured:

1. Create an Ubuntu virtual machine
2. Select the previously created VNet and subnet
3. Configure authentication and access settings
4. Ensure the VM uses a private IP address
