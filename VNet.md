# STEP 1: Create Virtual Network (VNet)

## Overview

This step covers the creation and initial configuration of the Azure Virtual Network (VNet) used for the secure web application.

The VNet provides the isolated network environment for the application infrastructure and contains the required subnet configuration for the project.

## Configuration

The following network components are configured:

1. Create the Azure Virtual Network
2. Configure the VNet address space
3. Create the required application subnet
4. Configure the network structure required for Azure Bastion and Azure Firewall
